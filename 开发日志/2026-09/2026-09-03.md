- 现场复现为用户主目录右键可显示 OneBoard“新建文件”，iCloud 桌面空白处不显示；Finder 的无障碍路径把该桌面容器暴露为 `~/Library/Mobile Documents/com~apple~CloudDocs/`。

## 目标

- 用 cockpit-tools 同类的浏览器 OAuth 流程取代“保存当前登录”作为新增账号主入口。
- 用户填写邮箱、打开 Codex 官方授权页，浏览器授权成功后自动添加或更新账号。

## 实现

- 新增 `SystemCodexOAuthAuthorizer`：随机 PKCE verifier/challenge、随机 state、官方登记的 `localhost:1455` 回调、10 分钟超时和 OAuth token exchange。
- 授权链接直接使用 Codex CLI 标准形态请求 `https://auth.openai.com/oauth/authorize`，不经过 Codex Desktop 私有中转页。
- 从 `id_token` 读取已授权邮箱与套餐标识，从 access token 读取 ChatGPT account ID；填写邮箱与实际授权账号不一致时不保存。
- 认证缓存使用 Codex `type/tokens/last_refresh` 结构，仅保存在 OneBoard 的 macOS Keychain vault。
- 新增 OAuth 账号弹窗，保持 OneBoard grouped Form、颜色和系统控件风格。

## 授权与翻译故障修复

- 真实授权返回 `invalid_authorize_request` 的原因是 OneBoard 套用了 Codex Desktop 私有中转页和 Desktop 专用参数，页面又注入当前工作区信息，最终形成不兼容授权请求。
- OAuth 改为 `originator=codex_cli_rs` 的直接授权请求，移除 `codex_app_version`、`source_surface_stable_id` 和 `codex_origin_stable_id`。
- 实测随机 localhost 端口会被授权服务拒绝；回调固定为官方 Codex CLI 使用的 `http://localhost:1455/auth/callback`。
- Google 翻译失败可稳定复现为免费 Web 端点返回 HTTP 429 和自动查询拦截 HTML；现在识别限流并提示稍后重试或切换 Apple/DeepSeek，不再展示整页 HTML。
- 新增 OAuth URL 结构和 Google 429/HTML 回归测试。

## 安全边界

- OneBoard 不收集、代填或保存 OpenAI 密码、MFA 或邮箱验证码。
- OAuth 回调只监听本机 loopback，并且必须通过 state 校验才接受 authorization code。
- 切换仍必须先退出 Codex 并确认旧进程完全结束。

## Codex 账号额度与凭据自动续期

### 实现

- 参考 `cockpit-tools` 的当前实现读取 `wham/usage`，将服务端 `used_percent` 转换成设置页需要的剩余百分比，并展示 5 小时/每周窗口及重置时间。
- 从 usage 响应读取套餐和剩余主动重置次数；usage 未返回次数时单独查询重置凭证接口；从账号检查与订阅响应补充订阅到期时间，字段不可用时明确显示未知。
- App 启动后每 15 分钟顺序刷新所有账号，也支持设置页手动刷新；失败账号保留上次成功快照，不阻断其他账号。
- access token 提前 5 分钟续期；额度接口返回 401/403 时允许一次续期后重试，并保存服务端轮换后的完整认证缓存。
- 切换账号前先续期目标账号。当前账号正在 Codex 中运行时不由 OneBoard 旋转 refresh token，避免两个客户端并发使用造成凭据失效。

### 安全边界

- access token、id token 和 refresh token 仍只保存在 macOS Keychain；UserDefaults 仅保存剩余额度、重置时间、订阅到期、重置次数和错误提示。
- 自动续期不读取密码、MFA 或邮箱验证码，也不消费主动重置次数。
- 当前额度与订阅查询接口并非 OpenAI 公开稳定 API；实现按字段缺失和接口失败做降级，不伪造到期时间或额度。
