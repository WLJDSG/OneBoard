# 开发日志 - 2026-06-04

- [x] **马赛克增强**：加大马赛克块和遮挡强度，提升内容遮挡效果
- [x] **文件暂存**：去除顶部小黑条、右上角下拉箭头、底部半圆按钮；暂存窗口可拖动且内部文件仍可拖出
- [x] **拖拽唤醒**：在 CGEventTap 外新增高频轮询兜底，拖拽文件摇晃或进入顶部触发区都可尝试唤出暂存区

### v1.0.8 权限与截图焦点修复
- [x] **权限流程**：修复设置页定时同步反复激活 App 的问题，避免截图后抢走其他应用输入焦点
- [x] **权限完成态**：区分授权流程和移除流程；授权/移除完成后关闭系统设置和悬浮引导，再回到 OneBoard 设置页

- [x] **截图移动**：移动工具拖拽时持续更新拖拽基准点，修复截图窗口无法调整位置
- [x] **暂存唤醒**：轮询兜底不再因鼠标进入顶部区域而误触，仅在拖拽内容或已有拖拽轨迹时参与判断

### v1.0.9 截图标注与暂存区打磨
- [x] **截图标注**：工具栏贴近截图下方，移除文字工具；Esc 本地/全局按键兜底关闭截图标注窗口
- [x] **贴图窗口**：贴图改为纯图片窗口，双击图片直接关闭自身窗口
- [x] **OCR/翻译**：结果改为右侧磨砂悬浮窗展示，保持和截图工具栏一致的轻量风格
- [x] **箭头/直线**：绘制时固定第一次点击的起点，拖动期间只调整终点，避免起点乱飘
- [x] **马赛克**：改为更密集、更随机的遮挡纹理，提高遮挡强度
- [x] **文件暂存**：改为圆角磨砂透明悬浮框，文件以网格平铺展示，每个文件右上角可单独删除
- [x] **文件拖拽**：窗口拖拽区域和文件拖出区域分离，避免拖文件时暂存窗口跟着移动
- [x] **重复暂存**：对暂存文件做标准路径去重，避免从暂存区拖回时重复添加
- [x] **菜单栏图标**：改为透明底系统模板图标，去除蓝色底色

### v1.0.11 截图架构重构与多项UI修复
- [x] **截图流程重构**：完全替换系统 screencapture -i 命令，改为「冻结全屏 → 自定义框选 → 恢复屏幕」方案，避免动态内容导致截图失败
- [x] **截图窗口定位**：框选完成后窗口直接定位在选区位置，不再偏移到其他位置
- [x] **工具栏独立悬浮**：工具栏从截图窗口内部分离为独立 NSPanel，位于截图窗口下方 0.5cm；图片窗口和工具栏窗口移动联动
- [x] **拖拽顺滑优化**：将 SwiftUI DragGesture 替换为 NSEvent addLocalMonitorForEvents，窗口拖拽更流畅
- [x] **工具栏边界自适应**：工具栏超出屏幕右侧时自动左移，超出左侧时右移，保证完整显示
- [x] **颜色选择器重构**：8个色块收进一个颜色按钮，点击弹出预设颜色 + 系统 RGB 选色面板；截图默认颜色改为红色
- [x] **文字标注工具**：替换高亮笔工具为文字标注；点击文字图标 → 点击截图 → 弹出输入框 → 确认后生成文字图层；双击可编辑，可拖拽移动，Delete 删除，支持多个
- [x] **OCR/翻译弹窗位置**：在截图窗口右侧 1cm 处显示；右侧超出则自动切换到左侧
- [x] **辅助功能权限开关**：设置页新增辅助功能权限开关，和屏幕录制权限开关逻辑一致
- [x] **摇晃检测优化**：降低检测阈值（速度 100px/s / 位移 3px），提升轮询频率至 30ms，放宽触发条件
- [x] **剪贴板弹窗**：去掉标题栏/关闭按钮/底部状态栏，改为无边框磨砂面板；光标离开窗口自动关闭
- [x] **权限关闭流程**：revoke 模式下等用户手动关闭系统设置后再回到 App 设置；修复设置页跟随关闭的 bug
- [x] **权限开关状态**：流程完成后通知设置页强制刷新开关状态和文案，避免延迟更新
