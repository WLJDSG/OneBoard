# 开发日志 - 2026-06-04

## 今日完成

### v1.0.7 体验修复
- [x] **权限引导**：移除 App 内 NSAlert 弹窗，开启权限时直接打开对应系统权限页，并显示无标题栏磨砂引导浮窗
- [x] **权限状态同步**：授权成功后自动关闭权限引导浮窗并回到设置页；手动移除系统权限后，设置页开关会自动刷新为关闭
- [x] **截图默认行为**：新增“移动”工具并设为默认，打开截图后不会直接进入矩形绘制；拖动截图本体可移动截图窗口
- [x] **截图快捷键**：Esc 可关闭截图标注窗口；截图工具栏移除“格式”式样，文字工具改为输入光标图标
- [x] **截图保存和贴图**：保存面板置前显示；贴图窗口改为纯图片无边框；钉住后关闭原截图标注窗口
- [x] **马赛克增强**：加大马赛克块和遮挡强度，提升内容遮挡效果
- [x] **文件暂存**：去除顶部小黑条、右上角下拉箭头、底部半圆按钮；暂存窗口可拖动且内部文件仍可拖出
- [x] **拖拽唤醒**：在 CGEventTap 外新增高频轮询兜底，拖拽文件摇晃或进入顶部触发区都可尝试唤出暂存区

### v1.0.8 权限与截图焦点修复
- [x] **权限流程**：修复设置页定时同步反复激活 App 的问题，避免截图后抢走其他应用输入焦点
- [x] **权限完成态**：区分授权流程和移除流程；授权/移除完成后关闭系统设置和悬浮引导，再回到 OneBoard 设置页
- [x] **屏幕权限**：开启屏幕权限时不再因为其他权限已授权而提前关闭引导
- [x] **截图移动**：移动工具拖拽时持续更新拖拽基准点，修复截图窗口无法调整位置
- [x] **暂存唤醒**：轮询兜底不再因鼠标进入顶部区域而误触，仅在拖拽内容或已有拖拽轨迹时参与判断

### v1.0.9 截图标注与暂存区打磨
- [x] **截图标注**：工具栏贴近截图下方，移除文字工具；Esc 本地/全局按键兜底关闭截图标注窗口
- [x] **贴图窗口**：贴图改为纯图片窗口，双击图片直接关闭自身窗口
- [x] **OCR/翻译**：结果改为右侧磨砂悬浮窗展示，保持和截图工具栏一致的轻量风格
- [x] **箭头/直线**：绘制时固定第一次点击的起点，拖动期间只调整终点，避免起点乱飘
- [x] **马赛克**：改为更密集、更随机的遮挡纹理，提高遮挡强度
- [x] **文件暂存**：改为圆角磨砂透明悬浮框，文件以网格平铺展示，每个文件右上角可单独删除
- [x] **文件拖拽**：窗口拖拽区域和文件拖出区域分离，避免拖文件时暂存窗口跟着移动
- [x] **重复暂存**：对暂存文件做标准路径去重，避免从暂存区拖回时重复添加
- [x] **菜单栏图标**：改为透明底系统模板图标，去除蓝色底色

### v1.0.10 UI 细节修复
- [x] **暂存区圆角**：修复暂存区悬浮框四个角有直角底色的样式问题；SwiftUI 层使用 clipShape + background 分离实现圆角和阴影，NSHostingView 层设置 cornerRadius + masksToBounds 兜底
- [x] **暂存区流畅度**：添加 `pendingFilePaths` 集合防重复竞态；窗口 resize 关闭动画（animate:false）避免卡顿
- [x] **权限关闭流程**：关闭授权开关时仅打开系统权限页，不再弹出悬浮引导窗；轮询检测权限移除后自动关闭系统设置并回到 App 设置页
- [x] **截图窗口拖拽**：修复 AnnotationViewModel.startDrawing 在 cursor 模式下不设 isDrawing 导致每帧重置拖拽基准点的 bug
- [x] **截图窗口定位**：在截图开始前记录鼠标位置，窗口优先定位在框选区域附近而非截图完成后的鼠标位置
- [x] **工具栏自适应**：工具栏改为横向 ScrollView 包装，移除 fixedSize() 约束，窄窗口下可横向滚动保证按钮完整显示
