### Bug 修复：PasteboardMonitor 架构问题
- [x] **修复**：复制后很久才能在剪贴板看到（数据流断连导致 UI 不刷新）
- [x] **修复**：清空后新内容不再出现（同上根因）
- [x] **根因**：PasteboardMonitor 通过通知传递数据，AppDelegate 创建临时 ViewModel 保存到 DB，但 Popover 的 ViewModel 是另一个实例，两者不互通
- [x] **修复方案**：PasteboardMonitor 直接保存到数据库 → 发通知 → ViewModel 监听通知自动刷新
- [x] 修改文件：PasteboardMonitor.swift、AppDelegate.swift、ClipboardListViewModel.swift

### Bug 修复：点击条目无法粘贴
- [x] **修复**：点击条目后 Cmd+V 发到了 Popover 自身，目标应用收不到粘贴事件
- [x] **根因**：`simulatePaste()` 在 `togglePopover()` 之前执行，按键事件被 Popover 窗口拦截
- [x] **修复方案**：改为"写入剪贴板 → 关闭 Popover → 延迟 0.15s → 模拟 Cmd+V"，确保粘贴事件到达目标应用
- [x] 新增 `isPasting` 标记，在粘贴操作期间暂停 PasteboardMonitor，避免重复记录自己的粘贴
- [x] 修改文件：ClipboardListViewModel.swift、PasteboardMonitor.swift

### Bug 修复：Popover 关闭后无法恢复前台应用
- [x] **修复**：Popover 关闭后目标应用不恢复焦点，导致手动粘贴也失败
- [x] **根因**：Popover 打开时 `NSApp.activate` 将 OneBoard 激活，关闭后系统不自动切回原应用
- [x] **修复方案**：MenuBarManager 新增 `previousApp` 属性，打开前保存当前前台应用，关闭后 `app.activate()` 恢复
- [x] 修改文件：MenuBarManager.swift

### Bug 修复：自动粘贴需要权限引导
- [x] **修复**：CGEvent 模拟 Cmd+V 需要辅助功能权限，之前静默失败，用户迷惑
- [x] **修复方案**：`simulatePaste()` 中检查权限 → 无权限时弹出引导对话框 → 引导用户去系统设置开启
- [x] PermissionManager 新增 `promptAccessibilityPermission()` 弹窗方法
