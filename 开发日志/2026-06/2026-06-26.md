# 2026-06-26 开发日志

## 菜单栏图标不可见 Bug 修复

### 问题描述
macOS 26.5.1（Darwin 25.5.0）上，OneBoard 安装后菜单栏图标完全不显示。
`NSStatusItem` 和 `MenuBarExtra` 均无法渲染。

### 设备信息
- MacBook Pro 13英寸 M3 2024（刘海屏）
- macOS 26.5.1
- 屏幕 1470×956，顶部 notch 区域 62-64px

### 排查过程（耗时 3h+，40+ 次构建测试）

1. **排除图标渲染问题**：SF Symbol、自定义 NSBezierPath、纯色圆点、纯文字均不可见
2. **排除 API 兼容性**：`NSStatusItem` 和 `MenuBarExtra` 均失败
3. **排除依赖问题**：逐库测试 GRDB、KeyboardShortcuts、LaunchAtLogin，单个和组合均无问题
4. **定位到 app bundle**：裸二进制可显示，app bundle 内不可显示
5. **定位到 Info.plist**：删除 Info.plist 后可显示
6. **定位到 CFBundleIdentifier**：最小 Info.plist 中只有 `CFBundleIdentifier = com.oneboard.app` 时不可见，换成其他 ID 可见

### 根因

1. **主要根因**：`com.oneboard.app` 在系统 Launch Services 数据库中有永久残留记录（反复安装/卸载累积）。macOS 26 上 `lsregister -kill` 已被 Apple 移除，`lsregister -u` 无效，无法清除。

2. **次要发现**：同模块编译时（所有源码在可执行 target 中），某些编译产物会干扰 NSStatusItem。通过模块隔离（可执行 target 只含 main.swift）解决。

### 修复方案

#### 架构改动：模块隔离
```
OneBoard (可执行模块 - 极简)
  └── App_minimal/main.swift       # 入口点：创建 NSStatusItem

OneBoardKit (业务库)
  ├── App/AppDelegate.swift        # 生命周期管理
  ├── Shared/MenuBarManager.swift  # 浮动窗口 + 菜单栏配置
  ├── Core/ Modules/ ...           # 其余所有代码
  └── 依赖：GRDB + KeyboardShortcuts + LaunchAtLogin
```

#### Bundle ID 更换
- `com.oneboard.app` → `com.oneboard.mac`（干净新 ID）

#### 防污染机制
- `script/build_app_bundle.sh` 支持 `ONEBOARD_BUNDLE_ID_SUFFIX` 环境变量
- 开发时：`ONEBOARD_BUNDLE_ID_SUFFIX=.dev bash script/build_app_bundle.sh`
- 正式发布：`bash script/package_app.sh`

#### 卸载功能
- 菜单新增「彻底卸载并清理残留...」
- DMG 附带「卸载残留.command」
- `script/uninstall.sh` 完整卸载脚本

### 修改的文件
- `Package.swift` — 拆分为 OneBoard + OneBoardKit 双模块
- `App_minimal/main.swift` — 新入口点，创建 NSStatusItem
- `App/AppDelegate.swift` — 恢复完整功能，public 导出
- `App/OneBoardApp.swift` — 移除 @main，仅保留 SettingsTab/SettingsWindowManager/SettingsView
- `Shared/MenuBarManager.swift` — 新增 configure(statusItem:)、runUninstaller()，移除 NSStatusItem 创建
- `Resources/Info.plist` — Bundle ID 改为 com.oneboard.mac
- `script/build_app_bundle.sh` — 新增 ONEBOARD_BUNDLE_ID_SUFFIX 支持
- `script/package_app.sh` — DMG 包含卸载脚本
- `script/uninstall.sh` — 新建，完整卸载脚本

### 验证
- `swift build -c release --disable-sandbox` ✅
- `script/package_app.sh` → DMG 创建 + 校验 ✅
- DMG 安装后启动 → 菜单栏图标可见 ✅
