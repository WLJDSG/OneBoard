# 2026-08-31 Codex 桌面多账号切换

## 需求与边界

- 在 OneBoard 中保存、重命名、删除和快速选择多个 Codex/ChatGPT macOS 桌面账号。
- 登录、密码和验证码全部由 Codex 发起的 OpenAI 官方浏览器页面处理；OneBoard 不保存密码或验证码。
- OneBoard 不主动退出或重启 Codex。运行中点击账号只进入等待，用户手动退出后才切换认证缓存，再由用户自行重开。
- 本功能不处理 Codex CLI。

## 实现

- 新增 `Modules/CodexAccounts`，按 Model / Service / ViewModel / View 分层。
- 账号名称和时间戳保存到 UserDefaults，认证缓存保存到 macOS Keychain，service 为 `com.oneboard.mac.codex-auth-cache`。
- 切换目标先校验钥匙串缓存；检测 `com.openai.codex` 连续两次不在运行后，保存当前账号刷新后的缓存，再原子恢复目标 `~/.codex/auth.json`。
- 认证文件要求是非空 JSON 对象，拒绝符号链接，目录和文件权限分别为 `0700`、`0600`。
- 设置页沿用 grouped Form、系统按钮、SF Symbols 和现有状态色；菜单栏新增账号快捷子菜单。
- App 内延迟卸载、仓库卸载脚本和 DMG 卸载入口同步清理本功能的钥匙串项。
