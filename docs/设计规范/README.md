# OneBoard 设计规范

## 2026-09-06 设置页密度

顶部只保留窗口控件所需的最小安全间距；删除无操作价值的说明、预览区和二次确认。可排序列表以整行作为拖放目标。

## 2026-09-06 快捷键与图标交互修订

菜单栏图标统一中等线重、18pt 画布、自适应单色；网速双行紧凑布局。键盘格显示目标图标、Option 键位和名称，类型选择使用锚定弹出菜单。截图主工具条保留图标分组，参数收进弹出面板，取色器独立可见。

## 2026-09-06 17:12 交互与文件类型修订

日历两侧 header44/筛选24/间距14/padding20，单一基线。状态卡片限制高度并允许滚动，进度条自行绘制保持非激活彩色；指标使用悬停底色。截图工具栏移除重复分组底色，颜色集中弹出选择，触发圆点反映当前颜色。快捷启动使用四行键盘式网格。

## 2026-09-06 悬浮卡片

日历/状态采用无标题栏圆角卡片，靠右上角显示。日历标签使用图标、低饱和蓝底和下划线选中态，置顶按钮清晰区分状态。刘海中转区使用黑色顶部、暗紫渐层和双投放卡片。长截图增加独立窄预览和小型图标控制栏，选区外变暗但鼠标透传。不得为视觉展示伪造运行指标。

## 2026-09-06 双栏面板

日历采用六行、周数、蓝色今天圆环、节日暖色标签、节气蓝色标签、班/休徽标和轻质感双栏；标题栏与月份导航分离。剪贴板保留搜索/筛选和左右预览，移除多余关闭按钮。备份页只需开关，显示固定位置、明文风险及恢复入口。菜单栏 18pt 单色模板叠层面板图标适配深浅色。

## 布局规范

### Popover（剪贴板列表）

- 宽度：350pt
- 高度：500pt
- 圆角：系统默认
- 行为：.transient（点击外部自动关闭）

### 列表项

- 内边距：水平 10pt，垂直 7pt
- 图标尺寸：28×28pt
- 预览文字：12pt，最多 2 行
- 时间标签：10pt，右对齐，宽度 55pt
- 行间距：2pt

### 搜索栏

- 背景：主色调 8% 透明度
- 圆角：8pt
- 内边距：水平 10pt，垂直 6pt

### 截图遮罩与工具栏

- 每块显示器使用独立的全屏半透明遮罩，遮罩尺寸严格等于该屏幕的 AppKit 逻辑点尺寸。
- 框选完成后保留边框、尺寸标签和八个缩放控制点；工具栏优先放在选区下方，空间不足时移到上方，并始终限制在当前屏幕内。
- 调整阶段直接显示完整标注工具栏；进入标注后复用原工具栏，不切换成另一套外观或按钮集合。
- 点击任意标注工具后立即锁定选区并安装原位画布，锁定后隐藏缩放控制点且禁止移动范围。
- OCR、翻译、复制、保存和贴图使用锁定瞬间的区域；OCR/翻译结果窗口显示前必须先移除所有屏幕遮罩。Google 返回限流 HTML 时只显示简短、可执行的中文提示，不输出 HTML 正文。

### Codex 账号设置

- 设置侧栏使用 `person.2` 图标，内容继续采用系统 grouped Form，与网关设置页保持同一信息密度和边距。
- 账号授权区展示 Codex 进程、当前账号和认证缓存三项状态，并以带 `plus` 图标的主入口打开新增账号弹窗。
- 新增弹窗使用 grouped Form，包含 OpenAI 账号邮箱、OAuth 说明、官方浏览器授权主按钮、等待进度和可复制的授权链接；链接直接指向 OpenAI 标准授权端点，不经过 Codex Desktop 私有中转页。
- 账号行使用 `person.crop.circle`，当前账号显示绿色 checkmark 与“当前”，目标账号切换时显示主色“切换中”。
- 账号标题旁显示套餐胶囊；详情区并排展示 5 小时和每周剩余额度进度条、对应重置时间，并在下方展示订阅到期、剩余重置次数与最近更新时间。
- 已保存账号标题区提供“刷新额度”；后台刷新时账号行显示小型进度指示，单账号失败在原行显示橙色可操作原因并保留上次成功快照。
- 删除使用无边框红色 `trash` 图标并二次确认；确认文案需说明删除数据库凭据，以及只有切换操作才会退出 Codex。
- 切换状态独立成组并使用小型 `ProgressView`；切换期间禁用其他账号操作，避免并发切换。
- 菜单栏“Codex 账号”子菜单复用当前/切换中状态标记，并提供“管理 Codex 账号...”入口；选择账号后显示最终成功或可恢复失败信息。

### 敏感操作确认

- 网关切换、卸载网关 Helper 和 App 内彻底卸载使用 macOS 系统身份验证面板，优先展示 Touch ID；没有可用指纹时允许输入 Mac 登录密码。
- 首次安装或升级网关 Helper 的系统管理员授权由 macOS 独立展示，不叠加第二个 OneBoard 身份验证面板。
- 用户取消或验证失败时停留在当前界面并显示系统原因，不执行后续网关或卸载操作。

### AI 模型设置

- 设置侧边栏使用“AI 模型”独立页，不与“Codex 账号”混合；顶部用分段控件切换 Codex / Claude Code。
- 配置行显示供应商名称、模型 ID 和地址，当前配置使用绿色 `checkmark.circle.fill`。
- 配置行追加额度摘要；官方 Codex 显示活动账号的 5 小时/每周剩余百分比，第三方配置通过内置接口显示真实额度，页头提供统一刷新入口。
- 新增/编辑弹窗使用固定标题与操作栏、可滚动内容区，并按“基本信息”“连接与鉴权”“高级兼容设置”“Claude Code 模型槽位”分组；普通用户只需完成基本信息与鉴权，高级兼容设置和 Claude 模型槽位默认折叠。
- API Key 从 SQLite 载入后默认遮蔽，可由用户主动显隐和直接更新；界面必须明确提示密钥只保存到 `oneboard.sqlite`，不使用钥匙串。
- Claude Code 编辑弹窗把鉴权字段放入高级选项并解释选择规则：代理通常使用 `ANTHROPIC_AUTH_TOKEN`，供应商明确要求 X-Api-Key 时使用 `ANTHROPIC_API_KEY`；模型映射按 CC Switch 的“角色、显示名称、实际请求模型、1M”表格展示，提供一键设置和独立默认兜底模型。
- 页面提供“从 CC Switch 导入”按钮，完成后显示导入数量和被跳过的配置名，不展示任何密钥。
- 高级兼容设置提供上游格式、完整 URL、User-Agent、备用端点、测速/自动择优、请求头/请求体 JSON 覆盖及按协议显示的缓存/模拟选项；默认折叠并提示仅特殊中转站需要配置，隐藏与当前协议无关的字段，DeepSeek 地址自动选择 OpenAI Chat Completions。
- 自定义 Codex 供应商生效后，Codex 模型选择器使用供应商名称展示当前模型，不再混入官方 GPT 选项；切回官方供应商后恢复 Codex 内置模型目录。
- 官方配置只要求名称和模型 ID；自定义 API 额外要求 HTTP(S) 地址和 API Key。
- 编辑弹窗同时提供“保存”和“保存并切换”；保存当前活动配置会立即重载运行配置，避免 SQLite 新 Key 与代理内存旧 Key 不一致。
- Codex Desktop 正在运行时，切换操作显示进行中状态，完成退出、配置写入和重新打开后才报告成功；重开失败时明确提示用户手动打开。
- 页底恢复操作明确说明配置文件路径、保留字段和 Codex 活动密钥的明文边界。
- 菜单栏“AI 模型”下按工具分两级子菜单，勾选当前项并提供管理入口。

### Finder 新建文件

- 受支持的本地桌面空白处展示“新建文件”三级菜单，类型顺序固定为 txt、docx、xlsx。
- iCloud Drive 和启用 iCloud 同步的桌面由 File Provider 管理，设置页明确说明 Finder Sync 无法在其空白处添加菜单。
- Finder 未返回目标 URL 时仅允许桌面容器菜单回退，并使用真实用户目录下的 `~/Desktop`，不得使用扩展沙盒内解析出的 Desktop。

## 图标

- 应用图标：`square.on.square`（SF Symbol）
- 类型图标：使用 SF Symbol 系统图标
- 置顶图标：`pin.fill` / `pin.slash`
- 删除图标：`trash`

## 交互规范

1. **悬停效果**：列表行悬停时显示主色调 8% 背景 + 操作按钮
2. **点击粘贴**：点击条目 → 写入剪贴板 → 模拟 Cmd+V → 关闭 Popover
3. **右键菜单**：支持右键操作（粘贴、置顶、删除）
4. **搜索防抖**：输入后 300ms 触发搜索
5. **快捷键**：可自定义，默认 Cmd+Shift+C（剪贴板）、Cmd+Shift+A（截图）、Cmd+Shift+D（暂存架）
6. **多屏一致性**：截图交互只作用于当前框选屏幕；外接屏与主屏的缩放比例不同也不得改变工具栏位置、裁剪比例或标注方向
7. **首笔连续性**：选择工具或直接开始绘制时，画布切换不得吞掉第一次鼠标按下，首个标注必须从按下位置开始
8. **Codex 进程边界**：点击账号后依次执行退出、确认进程消失、切换凭据和重新打开；进程未完全退出时禁止提交新凭据

## 动画

- 悬停过渡：0.15s easeInOut
- Popover 弹出：系统默认动画

## 2026-09-05 模型目录选择与额度说明

实际请求模型统一使用可编辑原生下拉框，允许从当前凭据返回的模型列表选择或手动填写；目录获取不再通过独立 Picker 修改默认兜底。额度刷新按钮标注「刷新额度与用量」。

## 2026-09-05 第三方额度、Token 统计与翻译 Key 选择

- 额度：内置 DeepSeek、Sub2API、SiliconFlow、OpenRouter 查询。自动识别官方域名，其他同源地址尝试 Sub2API `/v1/usage`；可在编辑页选择额度接口类型。失败显示 HTTP 状态及服务端原因，旧快照标明时间；不执行导入脚本。
- 统计：按 API Key 和供应商源分组，展示当日、累计、缓存命中 Token，展开查看输入、输出和缓存写入。相同 Key 的 Codex/Claude 配置共享本地统计，换 Key 后分开计算。
- 数据源：Sub2API 有历史用量时展示供应商当日/累计快照；OneBoard 本地统计仅覆盖启用后通过内置代理或翻译的请求，按本机时区计算自然日，包含缓存 Token 且不重复相加，不与供应商统计合计。余额接口未返回 Token 时不推算历史 Token。
- 存储：代理复用 CC Switch 的响应解析，向 stdout 输出无正文、无 Key 的计数事件；主应用写入 oneboard.sqlite 的 ai_usage_events，按请求 ID 去重。Key 仍仅在 SQLite 和代理内存中；正常退出刷新尾部计数，异常强杀可能丢失尚未输出的短暂内存事件。
- 翻译：设置页选择默认 API Key；翻译窗口可临时切换具体供应商配置，复用其默认模型、连接及协议，支持 Chat Completions、Responses、Anthropic Messages 和 Gemini；不改变 Codex/Claude 活动配置，也不再单独填写 DeepSeek Key。

## 2026-09-05 设置页整体视觉升级

参考 cockpit-tools 本地 settings_page.png 及 sidebar.css 的视觉语言，使用蓝青轻渐变、悬浮侧栏、低饱和选中态和白色卡片。统一 28pt 内容边距、18pt 卡片圆角、13pt 字段、27pt 页标题；选择器/开关右对齐，主操作使用蓝色按钮。深色模式使用自适应背景、文字和强调色。

## 2026-09-05 功能分布与面板视觉

- 设置侧栏：日常工具（剪贴板、文字识别、翻译、待办、文件与 Finder）、连接与账号（AI 模型、Codex 账号、网关）、应用（快捷键、授权、关于）。
- 菜单栏：日常操作置前，连接切换居中，设置/维护/退出置后；保留原生键盘导航和系统外观。
- 独立页面使用 20pt 外圆角、蓝青渐变底、38pt 图标容器、16pt 标题、11pt 副标题、语义文字色和统一关闭按钮。翻译将服务选择移到内容区，语言/输入/结果/状态/操作自上而下排列。
- 网关以卡片显示配置与当前状态，底部管理入口；文件暂存以拖放容器和网格组织，明确移除不删除原文件；待办和剪贴板保留搜索与列表，历史统计使用独立卡片。
- 深浅色、最小窗口与有内容状态需要实际渲染检查。截图遮罩、贴图和标注工具栏不套用功能面板背景。

## 2026-09-05 截图预选与输出

窗口悬停沿用蓝色边框和尺寸标签，不显示调整手柄；单击提交后出现手柄与完整工具栏。直接拖动替代候选窗口范围。翻译入口使用 character.bubble 图标和“翻译”文字，放在 OCR 与完成之间。贴图保持无装饰图像，保留双击关闭和捏合缩放。

### 窗口预选稳定性修正（2026-09-05）

窗口预选使用冻结截图背景，窗口内部亮度和内容保持原图，外部压暗。按下和小幅抖动不闪回全屏提示，也不出现零尺寸框；明显拖动后才显示自定义矩形。

### 2026-09-05 授权与操作反馈

选区工具栏的翻译动作直接消费当前选区；空文字快捷键不显示反馈窗口。权限不足先展示授权引导。网关面板在安装授权、指纹验证和切换期间持续显示进度，完成后保留成功或失败状态。额度查询错误不得使用“本地代理失败”措辞。菜单栏日常工具与文件设置提供“在桌面新建文件”入口，供 iCloud 桌面使用。

### 2026-09-05 设置首次打开崩溃修复

设置页先完成窗口展示，后台更新 Helper 授权状态，不用同步系统命令阻塞窗口布局。

## 2026-09-06 iCloud、日历与翻译设置视觉

- iCloud 页面用状态卡展示总开关、最近同步、立即同步与准确的同步范围；错误保留在页面，不用“系统繁忙”遮盖原因。
- 未携带有效 iCloud 签名能力的本地包禁用同步开关并解释需要正式签名包，不因缺少 entitlement 在启动时闪退。
- 日历页面按“日历显示、菜单栏日历、预览”分区；月历保持 7 列、当日强调色圆点、跨月日期弱化。
- 菜单栏日历采用独立 `calendar` SF Symbol，关闭后立即移除；OneBoard 主菜单仍提供日历入口。
- 翻译引擎以三张等宽选择卡展示系统、Google、自定义 API；自定义字段按预设、地址、Key、模型、状态与操作纵向排列。
- 长截图按钮与框选工具栏并列，不压缩或替换完整 `AnnotationToolbarView`。
# 2026-09-06 截图与选择器

- 应用/工具选择器使用图标网格、名称与搜索，不要求用户输入路径或内部工具 ID。
- 截图工具栏使用单层玻璃材质、15pt 连续圆角和清晰分组；长截图入口归入输出组。
- 长截图控制卡与预览卡统一材质、描边和阴影，完成操作使用主强调色；日历选中日期采用强调色填充加 2pt 描边。
- 长截图范围采用四角短线，不显示贯穿全高的边界线；文字工具的字号步进器内联显示。刘海暂存以 0.30 秒从顶部中央展开、0.24 秒反向缩回，两个投放区均整块响应拖放。
