## 设计总览

### 统一规则（所有 7 个页面强制执行）

| 规则 | 值 |
|------|---|
| 面板材料 | `.regularMaterial` |
| 面板圆角 | `radiusLG` (12pt) |
| 面板阴影 | `shadowLG`（暖灰，非纯黑） |
| 面板边框 | 无（material 自带层次） |
| 关闭按钮 | xmark，28×28pt，textSecondary，header 右侧 |
| 置顶按钮 | pin/pin.fill，28×28pt，accent（激活时），header 右侧 |
| 文字色 | 只用 textPrimary / textSecondary / textTertiary |
| 强调色 | 只用 accent（#D4792E）— 按钮、选中、关键图标 |
| SF Symbols | 全用 systemName，不用 emoji |

## 页面 2：剪贴板面板

```
┌────────────────────────────────┐
│ 🔍 搜索剪贴板...          ⌘F  │  ← 搜索栏，surface 背景，8pt 圆角
├────────────────────────────────┤
│ 📌 已置顶                     │  ← 分区标签（仅当有置顶项）
│  ┌───────────────────────────┐ │
│  │ 📋 置顶文字内容...  2分钟 │ │  ← 暖色 accentLight 背景
│  └───────────────────────────┘ │
│ 📋 普通文字内容...    1小时前 │  ← 透明底，hover → accentLight
│ 🖼️ 屏幕截图.png       3小时前 │
│ 📄 文档.pdf            昨天   │
├────────────────────────────────┤
│ 📊 共 128 条 · 保留 30 天     │  ← 底部状态栏，36pt
└────────────────────────────────┘
```

### 设计细节

| 元素 | 规格 |
|------|------|
| 面板 | 350×520，material，12pt 圆角，暖灰阴影 |
| 搜索栏 | surface 背景，8pt 圆角，body 字体 |
| 置顶区 | accentLight 背景（8%），上缘 6pt 圆角 |
| 普通行 | 透明底，hover → accentLight，6pt 圆角，40pt 高 |
| 类型图标 | 28×28pt，accentLight 底 + accent 色 SF Symbol |
| 操作按钮 | hover 时出现，36pt 宽，pin + trash 图标 |
| 时间标签 | caption 字体，textSecondary，右对齐 44pt |
| 底部栏 | caption 字体，textTertiary |

### 签名细节 ✨
置顶项的暖色 accentLight 背景 —— 不是黄色，而是和 amber 同色系的 8% 暖调。视觉上温暖但不突兀。

## 页面 3：待办面板

```
┌────────────────────────────────┐
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━  │  ← 拖拽手柄，warmGray 30%
│ ✓ 待办                   3 项  │  ← header
├────────────────────────────────┤
│ ＋ 添加待办...                 │  ← 快速输入行，40pt
├────────────────────────────────┤
│ ● 买咖啡豆            Safari  │  ← 行，40pt，左侧优先级圆点
│ ● 写完周报           VS Code  │
│ ○ 重构代码（已完成）   Xcode  │  ← 完成项 textTertiary + 删除线
│ ○ 整理文件            Finder  │
├────────────────────────────────┤
│ 🕐 历史                  ⌘H   │  ← 底部，36pt
└────────────────────────────────┘
```

### 设计细节

| 元素 | 规格 |
|------|------|
| 面板 | 320×480，material，12pt 圆角 |
| 拖拽手柄 | 36×4pt，warmGray 30%，4pt 圆角 |
| 快速输入 | 加号图标 + TextField，body 字体，surface 底 |
| 待办行 | 40pt 高，优先级圆点 10pt（红#C95A4A/橙#D4A03C/蓝#5B8DB8/灰） |
| 完成项 | textTertiary + strikethrough |
| 来源标签 | caption 字体，textTertiary |

### 签名细节 ✨
优先级圆点用暖色调配 —— 不是纯红/纯绿，而是暖调语义色。高优先级用暖棕红、中用琥珀、低用灰蓝。

## 页面 4：翻译面板

```
┌──────────────────────────────────────┐
│  🌐  翻译                       [×]  │  ← header，40pt
│      源语言 → 目标语言          [⇄]  │  ← 语言栏
├──────────────────────────────────────┤
│                                      │
│  ┌──────────────────────────────────┐│
│  │ 输入要翻译的文字...              ││  ← 源文本，surface 底，8pt 圆角
│  │                                  ││     14pt 字体
│  └──────────────────────────────────┘│
│                                      │
│  ┌──────────────────────────────────┐│
│  │ 翻译结果                         ││  ← 译文，同规格
│  │                                  ││
│  └──────────────────────────────────┘│
│                                      │
│  [Apple ▼]  · 使用系统翻译 · 支持离线│  ← 服务选择 + 状态
│                                      │
│  [翻译]              [复制原文][复制]│  ← 操作栏
└──────────────────────────────────────┘
```

### 设计细节

| 元素 | 规格 |
|------|------|
| 面板 | 480×min400~max650，material，12pt 圆角 |
| 语言栏 | 源语言 Picker → 交换按钮 → 目标语言 Picker，在 header 下方 |
| 文本区 | surface 底，8pt 圆角，14pt 字体，min 100pt 高 |
| 服务选择 | header 内 menu Picker（小），或底部信息栏 |
| 翻译按钮 | accent 填充按钮，body semibold，白色文字 |
| 复制按钮 | accent 浅底 + accent 文字 |

### 签名细节 ✨
翻译按钮的 accent 色（#D4792E 暖琥珀）在白色/毛玻璃背景上像一点温暖的火光。
