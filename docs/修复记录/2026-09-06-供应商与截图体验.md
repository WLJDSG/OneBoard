# 2026-09-06 供应商、权限与截图体验

## 实现

- 设置窗口仅标题栏拖动；供应商和 Codex 账号用明确拖拽手柄排序，邻项弹簧移位，目标位虚线占位。成功投放后持久化，Esc/移出取消还原；右键支持上移/下移，减少动态效果时关闭动画。
- 保持 AppDelegate 生命周期。显式退出不触发授权页重启；代理退出在后台有界等待，避免主线程无限阻塞。启动握手有超时。
- 添加供应商提供 22 个连接预设和自定义入口；预设配置请求地址/协议/已接入额度接口，特殊中转站兼容项仅自定义展开。高级项用于请求头、认证字段、协议转换与请求体覆盖，不是所有供应商的必填项。
- 完整推理 URL 自动识别，基础地址补足端点；模型目录独立解析。DeepSeek Claude 连接使用 `/anthropic`，模型目录固定源站 `/models` 并用 Bearer 鉴权，余额固定 `/user/balance`。模型仍来自用户当前 Key 的返回结果，不伪造预设模型目录。
- 自定义额度支持自动识别或手动 URL + 响应类型，只发送只读 GET，不执行脚本。尚未接入查询的预设明确引导供应商控制台。额度缓存包含 URL/解析类型，Token 统计仍按供应商源 + Key 共用。
- 快捷绑定直接进入对应应用/工具/快捷指令选择器，本地文件直接系统选择；选中即绑定。网页保留必要网址表单，移除旧通用绑定窗口。
- iCloud 后台轮询不发布“正在备份”等过渡文字，相同配置不重写备份、不刷新时间；手动操作保留进度。
- 授权页汇集现有系统授权、Helper、Finder、启动项，加上桌面/iCloud 本机访问书签、文件与文件夹/自动化/本地网络设置入口，以及账号/API Key 管理入口。后台启动不探测未授权 iCloud 目录；用户选择一次后保存安全作用域书签，书签不参与云备份。
- 系统没有公开的通用文件夹授权状态查询接口，因此页面明确显示“已保存本机访问书签”，不把它冒充系统实时授权状态。移除书签和撤销 macOS 权限分别说明。敏感网关操作仍需设备身份验证；首次 Helper 安装仍走系统管理员授权。
- Mac 状态磁盘采样改用文件系统容量，避免周期调用重要用途容量查询。每次启动的文件夹请求有多种可能来源，包括未持久化访问和应用签名变化；本次移除自动 iCloud 探测并持久化选择，实际安装后是否完全消除弹窗仍需验证。
- 字号 +/- 以 1 步进，在 1–20 循环；工具栏所有工具保持同一布局。文本拖动使用固定画布坐标和拖动起点，文字编辑只在小手柄拖动，避免覆盖输入区。
- 新增框选标注：画框后在箭头尾部输入文字，移动文字重新计算连接边界；选框、箭头和文字是同一图层，一次撤销/重做。输出前提交尚在输入的文字。
- 取色器实时显示 `RGB(r, g, b)`；⌘C 复制并采用当前颜色，单击采用颜色，Esc 取消。截图阶段采样冻结原图，避免取到遮罩/提示自身；支持每屏独立缩放和坐标。
- 窗口候选保留 WindowServer 前后顺序，纳入浮动卡片与菜单层级（至 popUpMenu），排除透明窗口。应用在同一窗口内部绘制、且没有独立系统窗口的卡片仍需手动框选。
- 长截图移除选区外四块全屏暗色遮罩，仅四角短标记、完成栏和预览；角标窗口无阴影。匹配拒绝重复纹理的歧义位移，静止页面局部状态变化不再错误追加，拼接使用原始像素底部增量，完成后不追加在途帧。
