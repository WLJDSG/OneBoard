## 账号与数据边界

- Codex 的显式关联账号通过既有账号服务完成验证、退出、认证缓存切换及重新启动。未关联的旧官方供应商仍使用当前客户端账号。
- Claude Code 流程参考本机 cockpit-tools 的 OAuth 实现；授权状态只在内存中，access/refresh token 与过期时间保存在 OneBoard SQLite 的 `claude_account_oauth` 命名空间。
- 激活 Claude 官方账号时，将 access token 物化至权限为 0600 的 Claude settings.json 的 `env.CLAUDE_CODE_OAUTH_TOKEN`，不向客户端写入 refresh token。清除受管 API Key/代理地址，保留未知配置与稳定备份；切回自定义供应商清除 OAuth 环境键。账号授权凭据与第三方 API Key 存储隔离，不使用 Keychain。
- 活动 Claude 账号接近过期时后台续期并更新新会话配置；服务端不轮换 refresh token 时保留原值。已启动的 Claude 进程仍持有启动时环境，长时间会话遇到过期需重开会话。
- Claude 原生认证优先级与 OAuth 环境变量说明：[官方认证文档](https://code.claude.com/docs/en/authentication)。不把账号授权流程用于 OneBoard 翻译或第三方请求代理。
