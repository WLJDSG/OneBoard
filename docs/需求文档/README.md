# OneBoard 需求文档

## 项目定位

一款 macOS 原生工具，整合截图、历史剪贴板、文件暂存、Finder 快速新建、网关切换和 Codex 桌面账号切换，提供简洁、高效的日常工作流体验。

## 功能需求

### 一、截图模块（参考 Snipaste）

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 区域截图 | P0 | 框选屏幕任意区域；松开后保留选区，可移动并通过四边、四角调整大小 |
| 多显示器截图 | P0 | 每块显示器独立捕获和显示遮罩；在哪块屏幕框选就裁剪哪块屏幕，不受主屏缩放比例影响 |
| 选区锁定 | P0 | 点击任意标注工具时锁定当前选区，锁定后不能再改变截图范围 |
| 原位显示 | P0 | 截图与标注窗口保持框选位置，不得发生上下镜像或无故跳动 |
| 统一工具栏 | P0 | 调整和标注阶段复用完整工具栏，避免两套工具栏的能力和行为不一致 |
| 贴图置顶 | P0 | 截图后贴在屏幕上，置顶不被其他窗口遮挡 |
| 文字标注 | P1 | 在截图上添加文字 |
| 直线标注 | P1 | 在截图上画直线 |
| 框选标注 | P1 | 矩形框标注 |
| 高亮标注 | P1 | 高亮某块区域 |
| OCR 文字识别 | P1 | 识别截图中的文字（默认 Apple Vision，可切换第三方 API）；显示结果前必须关闭截图遮罩 |
| 翻译 | P1 | 翻译截图中的文字（默认 Apple Translation，可切换 Google/DeepSeek）；由截图会话统一结束后打开结果窗口，Google 限流时不得向用户展示原始 HTML |

### 二、历史剪贴板模块（参考 Maccy）

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 全类型记录 | P0 | 文字、文件、图片、视频等 |
| 时间倒序排列 | P0 | 最新的在最上面 |
| 存储策略 | P0 | 可按天数（默认 30 天）或条数（默认 200 条）限制 |
| 置顶/删除 | P0 | 单条置顶或删除 |
| 搜索 | P0 | 支持搜索历史记录 |
| 点击粘贴 | P0 | 点击某条记录可直接粘贴到前台应用 |
| 菜单栏弹出 | P0 | 通过菜单栏图标弹出 Popover 界面 |

### 三、文件暂存模块（参考 Dropover）

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 拖拽触发 | P0 | 仅拖拽真实普通文件并晃动后弹出暂存小窗，移动应用窗口不得触发 |
| 文件暂存 | P0 | 支持文本、表格、图片、压缩包等普通文件；拒绝目录和 `.app` 应用包 |
| 全局置顶 | P0 | 小窗置顶在所有软件之上 |
| 拖出发送 | P0 | 切换到目标软件后，从小窗拖出文件发送 |

### 四、通用功能

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 开机自启 | P1 | 系统启动时自动运行 |
| 全局快捷键 | P0 | 每个模块有独立快捷键，可自定义修改 |
| 菜单栏图标 | P0 | 常驻菜单栏，点击弹出剪贴板列表 |
| 设置窗口 | P1 | 配置各项参数 |

### 五、Finder 快速新建

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 右键新建 | P0 | 在 Finder 文件夹或桌面空白处创建 txt/docx/xlsx |
| 桌面兼容 | P0 | 兼容本地 Desktop、Finder 暴露的 iCloud Drive 桌面容器根目录、iCloud Desktop、系统解析桌面路径及符号链接路径 |
| 沙盒隔离 | P0 | Finder 扩展只传递目标目录，主应用负责实际写入和选中新文件 |

### 六、网关切换

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| Profile 切换 | P0 | 支持网关 + DNS 或仅 DNS 模式，自动作用于当前默认路由对应的网络服务 |
| 最小权限 Helper | P0 | 只允许配置档中合法 IPv4，安装 Helper 与初始白名单只请求一次管理员授权 |
| 禁止权限降级 | P0 | Helper 因地址不在白名单而拒绝时直接报错，不得回退到管理员密码执行同一业务命令 |

### 七、Codex 桌面账号切换

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| OAuth 新增账号 | P0 | 用户填写 OpenAI 账号邮箱，OneBoard 生成标准 Codex CLI 形态的 PKCE 授权链接并直接打开 OpenAI 授权页；不得套用 Codex Desktop 私有中转页或参数，本机回调成功后自动保存账号 |
| 账号管理 | P0 | 支持新增、重命名和删除；删除时同步移除该账号的钥匙串认证缓存 |
| 安全切换 | P0 | 点击账号后先校验目标凭据，再退出 Codex 并确认主进程与旧 app-server 完全结束；之后保存当前账号刷新后的缓存并恢复目标缓存 |
| 进程控制 | P0 | 先请求 Codex 正常退出，超时后对残留目标发送 SIGTERM；凭据切换成功后自动重新打开 Codex |
| 官方存储兼容 | P0 | 按 `cli_auth_credentials_store` 兼容 `file`、`keyring` 和 `auto`，不在配置为钥匙串时强制写入 `auth.json` |
| 凭据边界 | P0 | 邮箱仅作为授权账号校验和显示元数据；不保存密码和验证码，认证缓存仅放 macOS 钥匙串，不写入 SQLite 或日志 |
| 菜单栏快捷入口 | P1 | 菜单栏子菜单展示当前、待切换及其他账号，并可进入完整管理页 |
| 账号额度概览 | P0 | 展示 5 小时与每周剩余额度、窗口重置时间、订阅到期时间和剩余主动重置次数；单账号失败不得阻断其他账号刷新 |
| OAuth 凭据续期 | P0 | 后台定时刷新账号状态，access token 临近到期、远端拒绝或切号前自动用 refresh token 续期并保存轮换结果；当前账号正在 Codex 中运行时暂缓 OneBoard 侧轮换 |

## UI 设计要求

- **风格**：简洁、直观
- **主色调**：淡蓝色 (#59A6F2)
- **布局**：菜单栏弹出式（Popover），不占用 Dock 空间
- **交互**：尽量少的点击步骤，支持键盘操作

## 技术约束

- **平台**：macOS 14.0+（部分系统翻译能力需要 macOS 15.0+）
- **语言**：Swift 5.9+
- **框架**：SwiftUI + AppKit
- **数据库**：SQLite（GRDB.swift）
- **权限**：辅助功能、屏幕录制
