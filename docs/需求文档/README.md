# OneBoard 需求文档

## 项目定位

一款 macOS 原生工具，整合截图、历史剪贴板和文件暂存三大功能，提供简洁、高效的日常工作流体验。

## 功能需求

### 一、截图模块（参考 Snipaste）

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 区域截图 | P0 | 框选屏幕任意区域进行截图 |
| 贴图置顶 | P0 | 截图后贴在屏幕上，置顶不被其他窗口遮挡 |
| 文字标注 | P1 | 在截图上添加文字 |
| 直线标注 | P1 | 在截图上画直线 |
| 框选标注 | P1 | 矩形框标注 |
| 高亮标注 | P1 | 高亮某块区域 |
| OCR 文字识别 | P1 | 识别截图中的文字（默认 Apple Vision，可切换第三方 API） |
| 翻译 | P1 | 翻译截图中的文字（默认 Apple Translation，可切换第三方 API） |

### 二、历史剪贴板模块（参考 Maccy）

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 全类型记录 | P0 | 文字、文件、图片、视频等 |
| 时间倒序排列 | P0 | 最新的在最上面 |
| 存储策略 | P0 | 可按天数（默认 30 天）或条数（默认 200 条）限制 |
| 置顶/删除 | P0 | 单条置顶或删除 |
| 搜索 | P0 | 支持搜索历史记录 |
| 点击粘贴 | P0 | 点击某条记录可直接粘贴到前台应用 |
| 菜单栏弹出 | P0 | 通过菜单栏图标弹出 Popover 界面 |

### 三、文件暂存模块（参考 Dropover）

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 拖拽触发 | P0 | 拖拽文件晃动后，右上角弹出暂存小窗 |
| 文件暂存 | P0 | 将文件拖入小窗暂存 |
| 全局置顶 | P0 | 小窗置顶在所有软件之上 |
| 拖出发送 | P0 | 切换到目标软件后，从小窗拖出文件发送 |

### 四、通用功能

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 开机自启 | P1 | 系统启动时自动运行 |
| 全局快捷键 | P0 | 每个模块有独立快捷键，可自定义修改 |
| 菜单栏图标 | P0 | 常驻菜单栏，点击弹出剪贴板列表 |
| 设置窗口 | P1 | 配置各项参数 |

## UI 设计要求

- **风格**：简洁、直观
- **主色调**：淡蓝色 (#59A6F2)
- **布局**：菜单栏弹出式（Popover），不占用 Dock 空间
- **交互**：尽量少的点击步骤，支持键盘操作

## 技术约束

- **平台**：macOS 15.0+
- **语言**：Swift 5.9+
- **框架**：SwiftUI + AppKit
- **数据库**：SQLite（GRDB.swift）
- **权限**：辅助功能、屏幕录制
