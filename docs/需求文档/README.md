# OneBoard 需求文档

## 2026-09-07 桌面浮窗可读性

日历与 Mac 状态使用随系统深浅色切换的不透明窗口底色，隔离桌面壁纸透色，并保留圆角、细边界及窗口阴影。日历非本月日期以次级文字和较轻字重区分，不对整格降低透明度；周数与 Mac 状态辅助信息提高可读性。改动仅作用于这两个浮窗，悬停、点击关闭和日历置顶行为保持原规则。

## 2026-09-07 文件拖动保持展开、刘海全域与权限精简

有效文件拖动期间暂存区自动展开并持续保持，松手后按鼠标位置恢复收起；不把旧 .drag 载荷或普通窗口拖动当成文件会话。刘海触发区使用系统实际刘海宽度，覆盖整个刘海及顶边，不向两侧扩张，底部仅保留 2pt 容差；普通悬停仍需连续 0.5 秒。暂存面板以顶部内凹肩线连接屏幕边缘，避免直角；展开收起仍保持不透明；原生窗口固定贴住屏幕顶边，仅内容从顶部中央缩放，并禁用系统默认窗口出场动画，避免叠加动画产生顶边闪缝。

文字与框选文字字号限制为 15–25，逐次加减 1，到边界停止；加减按钮整个 22×28pt 区域都可点击。文件拖动改为无权限轮询，移除输入监控监听、检测和设置入口，以及无实际 Finder Apple Events 调用的自动化声明。保留截图、选中文字/粘贴、提醒、用户目录授权等仍有用途的权限；卸载清理仍兼容历史授权记录。

## 2026-09-07 暂存接收与原位编辑回归

按最新要求移除暂存区右上角收起箭头，依靠移出自动收起。

刘海连续悬停 0.5 秒触发，移出后关闭；暂存区采用主要投放区、独立 AirDrop 区及文件卡片。色板不因马赛克消失，仅数值调节器有底框。已有文字单击出现与初次输入一致的控件，支持拖动，双击原位编辑。

## 2026-09-07 暂存拖放与标注视觉

文件可从 Finder 拖入暂存并再次拖出；失败显示原因。刘海面板展开与收起保持颜色不变。文字输入轻量、提交后无悬停边框；马赛克方格不随拖动边界拉伸。

AI 供应商与 Codex 账号可拖拽排序。Pro 仅返回周窗口时不显示伪造的 5 小时额度。快捷键选择本地目标或快捷指令后立即绑定；网页支持自定义图片和域名缩略图。

## 2026-09-06 长截图与刘海暂存回归修复

长截图只显示四角范围标记，不绘制贯穿选区全高的左右边线。选择文字标注后，字号减小、当前值、增大必须直接可点击。刘海暂存从顶部中央展开并反向缩回，接收 Finder 文件 URL 的现代和兼容载荷；拖入暂存与拖入 AirDrop 都必须覆盖完整投放区，AirDrop 仍由系统让用户选择收件人。

## 2026-09-06 快捷键与图标交互修订

绑定键位必须展示已绑定名称，点击先选类型，应用/工具再展示选择界面。全部全局键位固定 Option＋字母/数字。菜单栏应用、日历与网速统一单色视觉和高度；运行时长超过一天展示天数＋小时。截图工具栏包含取色器。

## 2026-09-06 17:12 交互与文件类型修订

本轮新增 18 项交互反馈及文件类型扩展：700ms 悬停、刘海一体定位/拖放、状态图标与指标设置/系统入口、日历相邻月份导航、即时单击预览、可视化快捷启动、截图调色菜单与长截图采样优化。Finder 支持 15 种内置后缀、自定义后缀及去除多余分隔。自定义后缀不承诺生成专有格式模板。

## 2026-09-06 菜单栏与顶部中转区

日历和状态卡片支持悬停/点击开启、移出延迟收起、再点击关闭；日历置顶不因移出/失焦隐藏。移除日历标题栏与交通灯。剪贴板双击执行原活动应用粘贴，单击只预览。长截图仅保留四角短标记，右侧连续结果预览，用户决定完成/取消。暂存区改为顶部中央刘海区，独立暂存和 AirDrop 投放入口。状态卡片只使用实测系统指标和自采样以来的进程流量。

## 2026-09-06 补充交互

剪贴板类型切换应安全销毁预览，移除右上角关闭按钮。日历固定六行双栏，包含农历、24 节气、已公布中国休假/补班、倒数日和待办。长截图手动滚动期间边框持续可见。iCloud 自动创建 app/oneboard 明文配置备份，用于重装恢复而非双机冲突合并。翻译选择/新增已有 AI 模型配置，菜单栏图标改为单色叠层面板。

## 项目定位

一款 macOS 原生工具，整合截图、历史剪贴板、文件暂存、Finder 快速新建、网关切换、AI 模型供应商切换和 Codex 桌面账号切换，提供简洁、高效的日常工作流体验。

## UI 设计要求

- **风格**：简洁、直观
- **主色调**：淡蓝色 (#59A6F2)
- **布局**：菜单栏弹出式（Popover），不占用 Dock 空间
- **交互**：尽量少的点击步骤，支持键盘操作

## 技术约束

- **平台**：macOS 14.0+（部分系统翻译能力需要 macOS 15.0+）
- **语言**：Swift 5.9+
- **框架**：SwiftUI + AppKit
- **数据库**：SQLite（GRDB.swift）
- **权限**：辅助功能、屏幕录制

## 2026-09-05 模型目录选择与额度说明

模型映射的六个实际请求模型字段支持目录选择和手动输入；获取目录不得改变已配置的模型。额度查询支持官方 Codex 及内置第三方接口，不支持时返回明确原因。

## 2026-09-05 第三方额度、Token 统计与翻译 Key 选择

- 额度：内置 DeepSeek、Sub2API、SiliconFlow、OpenRouter 查询。自动识别官方域名，其他同源地址尝试 Sub2API `/v1/usage`；可在编辑页选择额度接口类型。失败显示 HTTP 状态及服务端原因，旧快照标明时间；不执行导入脚本。
- 统计：按 API Key 和供应商源分组，展示当日、累计、缓存命中 Token，展开查看输入、输出和缓存写入。相同 Key 的 Codex/Claude 配置共享本地统计，换 Key 后分开计算。
- 数据源：Sub2API 有历史用量时展示供应商当日/累计快照；OneBoard 本地统计仅覆盖启用后通过内置代理或翻译的请求，按本机时区计算自然日，包含缓存 Token 且不重复相加，不与供应商统计合计。余额接口未返回 Token 时不推算历史 Token。
- 存储：代理复用 CC Switch 的响应解析，向 stdout 输出无正文、无 Key 的计数事件；主应用写入 oneboard.sqlite 的 ai_usage_events，按请求 ID 去重。Key 仍仅在 SQLite 和代理内存中；正常退出刷新尾部计数，异常强杀可能丢失尚未输出的短暂内存事件。
- 翻译：设置页选择默认 API Key；翻译窗口可临时切换具体供应商配置，复用其默认模型、连接及协议，支持 Chat Completions、Responses、Anthropic Messages 和 Gemini；不改变 Codex/Claude 活动配置，也不再单独填写 DeepSeek Key。

## 2026-09-05 设置页整体视觉升级

全部设置分类（通用、授权、快捷键、网关、AI 模型、Codex 账号、识别与翻译、待办与文件、关于）与相关编辑弹窗统一现代视觉。保留原有绑定、授权、切换、刷新、统计、导入、备份和删除路径。导航与内容均可独立滚动。

## 2026-09-05 功能导航与弹出页整理

设置按日常工具、连接与账号、应用三组组织。文字识别与翻译、待办与 Finder 文件配置各自独立，旧设置页标识继续有效。菜单栏必须可直接打开截图、翻译、剪贴板、文件暂存、待办和网关，配置入口集中在设置，清理与卸载放入维护子菜单并保留确认及系统授权。
