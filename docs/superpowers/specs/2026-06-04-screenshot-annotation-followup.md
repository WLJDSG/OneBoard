# Screenshot Annotation Follow-up Spec

## Scope

修复 2026-06-04 录屏反馈中的截图标注问题：

- 截图贴图在鼠标拖动时应连续跟手，不能每隔几帧才跳动一次。
- 选择文字工具后，点击截图应在点击处出现一个透明文字输入矩形。
- 文字输入矩形失去焦点时，非空文字提交为图片上的文字标注；空文字直接消失。
- 文字标注的矩形边缘可作为调整大小的交互入口。
- 点击颜色弹窗中的“更多颜色...”不应闪退，应打开系统 RGB 颜色面板并即时同步所选颜色。
- 鼠标悬浮到文字标注上时，文字本身不能发生位置跳动。

## Non-goals

- 不改变 OCR、翻译、复制、保存、贴图的功能流程。
- 不引入新的截图引擎或第三方颜色选择器。
- 不重写整体标注架构，仅修复当前交互缺陷。

## UX Behavior

- Cursor 工具用于拖动整张截图贴图，移动时每个鼠标拖动事件都更新窗口位置。
- Text 工具点击后，在截图坐标中显示半透明输入框；输入框没有确认/取消按钮，回车或失焦提交。
- 已提交文字显示在其 `rect` 内，选中态只显示边框或控制点，不改变文字布局。
- 文字标注边缘悬浮时显示可调整大小的提示，拖动边缘更新 `rect`。
- “更多颜色...”关闭预设颜色弹窗后打开 `NSColorPanel`，使用稳定 coordinator 作为 target。

## Error Handling

- 颜色面板 target 使用持久对象，避免 SwiftUI 临时 View 被 Objective-C selector 调用。
- 空文字失焦或回车时不创建图层。
- 拖动窗口结束时清理拖动状态，避免残留累积位移影响下一次拖动。
