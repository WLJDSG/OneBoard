# OneBoard Clipboard, Translation, and Staging Polish Spec

## Scope

本轮处理剪贴板、翻译和文件暂存区的几个体验问题：

- 剪贴板长文本行在鼠标悬浮后保持单行省略，不因操作按钮出现而换行。
- 剪贴板搜索框不自动聚焦；用户点击搜索框后可以正常输入并过滤历史。
- 翻译面板升级为独立工作台，可在面板内切换 Apple、Google、DeepSeek 翻译服务。
- Google 翻译使用网页版接口，不要求 API Key。
- Apple Translation 直接接入系统 Translation 框架，并将项目最低目标提升到 macOS 15+。
- 文件暂存区适度放大窗口、文件卡片和缩略图，提高预览清晰度。
- 文件暂存区关闭按钮和单文件删除按钮改为清晰、正规的圆形按钮；删除按钮视觉更克制，悬浮或聚焦时再强调红色。

## Non-goals

- 不重做剪贴板数据库结构和历史记录存储策略。
- 不新增 Google Cloud Translation API 支持。
- 不引入登录、账号或云同步。
- 不把文件暂存区改成完整文件管理器；仍保持轻量悬浮暂存架。
- 不改变截图、OCR 和标注工具的核心流程。

## UX Behavior

### Clipboard

- 列表项预览文本固定为一行，超出部分使用省略号。
- 悬浮时显示置顶和删除按钮，但行高、文本行数和整体布局不跳动。
- 搜索框保持手动点击聚焦；点击后输入应进入搜索框，而不是触发行点击、粘贴或关闭 Popover。
- 搜索结果随输入过滤历史记录，保留现有防抖策略。

### Translation Workbench

- 翻译面板顶部保留标题和关闭按钮。
- 标题下方新增服务切换控件：Apple、Google、DeepSeek。
- 新打开翻译面板时使用设置页中的默认翻译服务；用户可在面板内临时切换服务。
- 切换服务后，若原文非空，应使用当前原文和语言设置重新翻译。
- 语言栏包含源语言、交换按钮和目标语言。源语言为自动检测时，交换按钮禁用。
- 原文区可编辑，支持清空；译文区只展示译文。
- 错误和状态显示在底部状态区，不写入译文文本框。
- DeepSeek 缺少 API Key 时不发起请求，显示去设置提示。
- Google 使用网页版接口；接口失败时显示可理解的错误提示。
- Apple 使用系统 Translation 框架；项目构建目标提升到 macOS 15+ 后不再显示 macOS 14 占位错误。

### File Staging

- 暂存小窗宽度和内容高度适度增加，让文件缩略图更容易辨认。
- 文件卡片、缩略图容器和文件名区域保持稳定尺寸，避免添加或删除按钮出现时挤压布局。
- 缩略图生成尺寸提高，显示时使用更高质量的缩放。
- 窗口关闭按钮使用浅色圆形背景和清晰 x 图标。
- 单文件删除按钮使用小圆形按钮，常态更柔和，悬浮或聚焦时增强红色，避免突兀的贴片感。

## Architecture

- 翻译服务保持 Service Layer 结构，抽象出统一的翻译服务选择入口。
- Apple、Google、DeepSeek 分别作为独立客户端或服务实现，统一返回译文或结构化错误。
- 翻译面板 ViewModel 负责当前服务、语言、原文、译文、加载状态和错误状态。
- 设置页继续负责默认翻译服务和 DeepSeek API Key 配置。
- 剪贴板行视图仅调整布局约束，不改变 ClipboardEntry 模型。
- 文件暂存区优先调整 FileStagingView 和缩略图生成逻辑，不改变 staged_files 数据表结构。

## Error Handling

- Google 网页接口不可用、返回格式异常或网络失败时，显示“Google 翻译暂不可用，请稍后重试”一类短提示。
- DeepSeek 未配置 API Key 时，显示缺少 Key 的状态，并提供去设置入口。
- Apple Translation 失败时，显示系统翻译失败提示，不污染译文区。
- 搜索无结果时保持现有空态或列表空状态，不弹错误。

## Verification

- `cd OneBoard && swift build`
- 运行现有测试，尤其是翻译面板 ViewModel 相关测试。
- 手动验证剪贴板搜索框点击后可输入、过滤、清空。
- 手动验证长文本行悬浮时不换行、不跳动。
- 手动验证翻译面板可切换 Apple、Google、DeepSeek，并分别处理成功、缺 Key 和失败状态。
- 手动验证暂存区缩略图更清晰，关闭和删除按钮在普通、悬浮、点击状态下都清楚且协调。
