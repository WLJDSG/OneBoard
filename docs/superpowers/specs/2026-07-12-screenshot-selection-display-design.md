# 截图选区尺寸与透亮遮罩设计

## 目标

- Retina 屏幕上，截图结果窗口的显示尺寸与用户框选的屏幕区域一致。
- 保留裁剪图片的 Retina 原始像素，不降采样。
- 触发截图后显示全屏暗色遮罩；拖拽时框选区域透亮，框外继续保持暗色。

## 设计

### 尺寸与裁剪

`ScreenshotCropMapper` 继续将遮罩视图的点坐标映射为截图的像素坐标，使用映射后的矩形从 `CGImage` 裁剪，因此保留原始像素密度。

构造裁剪结果 `NSImage` 时，其逻辑 `size` 使用用户框选矩形的点尺寸，不再使用裁剪矩形的像素尺寸。下游标注窗口按 `NSImage.size` 布局，因此显示大小与框选大小一致，底层 `CGImage` 仍保留 Retina 像素。

### 遮罩绘制

`ScreenshotOverlayContentView.draw(_:)` 按以下顺序绘制：

1. 使用半透明黑色填充整个遮罩视图。
2. 当选区大于最小显示阈值时，将 Core Graphics 混合模式切换为 `.clear`，清除选区中的遮罩像素，再恢复 `.normal`。
3. 在透亮选区上绘制强调色边框和尺寸标签。

遮罩窗口本身保持透明，所以清除选区后会实时露出底下的屏幕内容，无需反复裁剪并绘制截图图片。

## 边界与错误处理

- 小于当前最小选区阈值的拖拽不确认截图。
- 裁剪矩形继续与原图像素边界取交集，避免越界。
- 不改变截图的保存像素、标注渲染或窗口生命周期逻辑。

## 验证

- 单元验证坐标映射在 2x Retina 比例下产生正确像素裁剪矩形。
- 构建应用后在 Retina 屏幕上实际框选，确认结果窗口逻辑尺寸与选区一致。
- 拖拽期间确认框外保持暗色，框内完全透亮，边框和尺寸标签可见。
- 重复截图并取消，确认不再发生 `NSWindow` 重复释放。
