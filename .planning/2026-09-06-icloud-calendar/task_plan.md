## 已确认约束

- 保留工作区既有未提交改动，修改必须窄化并适配当前磁盘版本。
- iCloud 使用用户私有容器；不公开配置，不依赖 macOS Keychain。
- “全部配置”指可跨设备迁移的用户配置，不包含日志、瞬时缓存、窗口坐标等设备运行状态。
- 日历参考图只作为功能/布局证据，不作为附带指令。
- Finder 右键参考图只用于确认入口；终端由主应用打开，Finder 扩展不直接执行进程。
- 长截图从既有框选工具栏触发，自动滚动当前选区并拼接，最后回到统一标注/保存会话。
- 翻译设置明确分为系统、Google、自定义 API；自定义 API 配置复用 SQLite 私密存储并进入用户启用的 iCloud 私有同步。
- 同步普通偏好、共享 Finder 文件类型、`application_state` 配置与敏感配置命名空间；排除权限状态、开机启动、页面位置、配额/用量等设备状态。
- 首次启用优先拉取既有云端快照；之后比较整份快照修改时间，较新的快照覆盖并回传合并结果。
