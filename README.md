# OneBoard

OneBoard 是一款常驻菜单栏的 macOS 原生工具，将截图、剪贴板、文件暂存、日历、系统状态、待办、网关切换和 AI 配置管理集中在一起。

使用 SwiftUI + AppKit 构建，配置保存在本机 SQLite。当前 SwiftPM 主程序目标为 **macOS 15.0+**，提供 Apple Silicon 本机构建流程。

## 功能概览

| 功能 | 可以做什么 |
| --- | --- |
| 截图与标注 | 窗口预选、自定义框选、多显示器截图、文字与图形标注、马赛克、贴图、手动长截图 |
| OCR 与翻译 | 识别截图文字、翻译选中文字；支持系统翻译、Google 和已有 AI 供应商配置 |
| 剪贴板 | 按类型筛选和搜索历史，单击预览、双击粘贴；文件使用系统 Quick Look |
| 文件暂存 | 拖入文件到屏幕顶部暂存区，再拖出使用或通过系统 AirDrop 分享 |
| Finder 新建 | 在受支持的 Finder 目录创建文件、打开终端；提供独立的桌面新建入口 |
| 日历 | 六行月历、农历、节气、已公布调休、倒数日和待办，支持滚轮切月与置顶 |
| Mac 状态 | 网速、进程用量、CPU、内存、温控、磁盘、电池和运行时间 |
| 待办 | 侧边待办面板、选中文字创建待办、完成反馈与历史记录 |
| 网关 | 保存并切换网关和 DNS 配置，通过系统身份验证与受限 Helper 执行 |
| AI 与账号 | 分别管理 Codex / Claude Code 模型供应商、官方账号、额度和用量 |

## 开始使用

1. 打开构建得到的 `OneBoard.dmg`，将 OneBoard 拖入「应用程序」并启动。
2. 从菜单栏 OneBoard 图标进入功能菜单或设置；日历、Mac 状态图标可以独立启停。
3. 在「快捷键」中选择 Option＋字母或数字，再绑定应用、文件、文件夹、网页、快捷指令或 OneBoard 工具。旧绑定迁移时保留已有占用。
4. 根据需要开启对应功能的系统权限。可以从「设置 → 授权」查看说明、管理权限和选择备份目录。

### 截图、标注与长截图

- 悬停预览鼠标下最前方窗口，单击采用窗口范围；直接拖动可自定义选区。程序坞的全屏交互层不会作为窗口候选。
- 选区可以移动和调整大小；选择标注工具后锁定选区。支持矩形、椭圆、线条、箭头、文字、框选文字、编号和马赛克，以及撤销/重做。
- 文字字号为 15–25，每次增减 1，到边界停止。文字双击原位编辑，选中后可移动和缩放；取色以 sRGB 显示，Command+C 复制颜色值。
- 全屏或近全屏选区上下放不下工具栏时，工具栏放在本屏 Dock 上方 12pt，避开顶部刘海。
- OCR、翻译、复制、保存和贴图统一结束截图会话后执行。每块显示器独立捕获和裁剪，贴图保留原始位图。
- 长截图由用户**手动向下滚动**，再点击完成或取消。选区外使用透传暗罩，边界只显示四角短标记；匹配不可靠时不追加内容。滚动过快、无重叠跳页或动态页面可能无法拼接。

### 日历与 Mac 状态

日历和 Mac 状态在图标上连续悬停 700ms 后打开，点击立即切换；移出图标与卡片 350ms 后关闭。再次点击关闭后，不会因鼠标留在原地立即重开。日历置顶后不会因移出而关闭。

- 日历左侧上滚切到上月、下滚切到下月，滚轮一次一月；触控板每个手势最多切一月，惯性不继续翻页。右侧列表独立滚动。
- 月历固定六行，提供农历、24 节气、节日和已公布的调休安排；未来未公布的调休不推算。
- Mac 状态使用 400×660pt 无滚动卡片，直接展示网络、三条应用/进程用量、性能、存储、电池和运行时间。
- 网速曲线保留近 60 次采样，进程流量是采样以来累计值；不把它描述为历史总流量，也不伪造温度或其他传感器数值。

### 文件暂存、剪贴板与 Finder

有效文件拖动期间，屏幕顶部暂存区展开并保持；松手后按鼠标位置恢复收起。普通悬停需连续停留 0.5 秒。暂存区使用系统文件 URL 拖放，AirDrop 收件人由用户在系统面板中选择。

剪贴板支持文本、图片、链接、颜色和文件的筛选与预览。单击查看内容，双击复制并粘贴到打开面板前的应用；自动粘贴需要辅助功能权限。

Finder 扩展只传递创建文件或打开终端请求，实际操作由主应用完成。支持内置文件类型和安全的自定义后缀；自定义后缀创建空文件，专有文档需要有效模板。iCloud Drive / iCloud 桌面的空白处菜单受 File Provider 限制，可使用 OneBoard 的「在桌面新建文件」入口。

### AI 供应商与官方账号

AI 模型配置与官方账号独立管理，分别作用于 Codex 和 Claude Code。

- 供应商配置支持新增、编辑、切换和拖拽排序，模型目录来自当前连接与 API Key。Claude Code 的默认、Haiku、Sonnet、Opus、Fable、子代理槽位独立配置，保留 1M 标记。
- 内置基于 CC Switch MIT 代码的 Rust 代理，支持常用协议转换、流式响应与高级兼容设置；运行时不依赖安装 CC Switch。可从其本地数据库导入配置，导入不会修改源数据。
- 模型切换保留客户端未知配置并生成备份。Codex 运行中会先退出并确认旧 `app-server` 结束，再写配置并重开；模型切换不会替换官方账号凭据。
- Codex 账号使用官方浏览器 OAuth；Claude Code 提供独立账号与授权页，保留授权码回填流程。OneBoard 不收集密码和验证码。
- Codex 额度按服务端返回的窗口时长分类，展示可获取的额度、重置时间、订阅及重置次数；不会将 primary 固定解释为 5 小时。当前账号正在 Codex 中运行时，OneBoard 暂缓并发刷新其凭据。
- 第三方额度支持 DeepSeek、Sub2API、SiliconFlow、OpenRouter。不可用时显示原因，旧快照标注时间；不执行导入的用量脚本。
- 用量按供应商源与 API Key 分组，区分供应商历史快照和本机代理/翻译统计，不将两者相加。本地统计只覆盖启用后经过 OneBoard 的请求。
- 翻译可以复用已有供应商配置，并在窗口内临时选择配置；不会切换 Codex / Claude Code 的活动配置。

### 网关切换

网关和 DNS 配置通过 OneBoard 专属 Helper 执行。首次安装或升级 Helper、写入初始白名单需要系统管理员授权；后续切换先使用 Touch ID 验证，未配置指纹时由系统回退到登录密码。白名单拒绝会直接报错，不会绕过 Helper 改用管理员 shell。

## 权限与数据

| 权限 / 授权 | 使用场景 |
| --- | --- |
| 屏幕录制 | 截图、长截图及屏幕取色 |
| 辅助功能 | 读取选中文字、向原应用自动粘贴 |
| 提醒事项等系统授权 | 使用对应提醒或待办集成功能时按需申请 |
| 文件夹选择 | 用户选择备份目录，保存本机目录授权 |
| 完全磁盘访问（可选） | 文件预览遇到系统保护目录拒绝时，由用户自行前往系统设置管理 |
| 系统身份验证 / 管理员授权 | 网关切换、Helper 安装升级和卸载 |

文件拖动检测不依赖输入监控权限，也不在拖入前读取文件属性探测受保护目录。完全磁盘访问不能替代屏幕录制、辅助功能或备份目录授权；其状态以系统设置为准，应用不会伪造开关或主动开启。

主要配置、AI Key、账号 OAuth 缓存、额度与用量保存在：

```text
~/Library/Application Support/OneBoard/oneboard.sqlite
```

凭据不使用 macOS Keychain。官方账号激活所需的客户端凭据按各自流程物化；Claude OAuth 不用于翻译或代理。内置代理运行时从内存接收 Key，受管客户端配置写入占位认证。可访问本机数据文件的用户仍应妥善保护它们。

### iCloud 配置备份

iCloud 当前用于**重装恢复的配置备份**，目录为 `iCloud Drive/app/oneboard`。启用并授权后保存 `configuration.json`，保留上一版；未下载或读取失败时不会覆盖备份，无变化时不重复写入。

备份包含设置、AI Key 和账号凭据，**没有额外加密，请勿分享备份目录**。剪贴板历史、临时截图、暂存原文件和本机目录授权不在备份中。旧 CloudKit / 加密实现仅保留兼容用途，不代表当前默认流程。

## 开发与构建

需要 Xcode / Command Line Tools、Swift，以及用于构建内置代理的 Rust/Cargo。SwiftPM 根目录是仓库中的 `OneBoard/`，打包脚本从仓库根目录执行。

```bash
# 全量测试与 Release 构建
cd OneBoard
swift test --disable-sandbox
swift build -c release --disable-sandbox
cd ..

# 生成正式 Bundle ID 的安装包并校验
bash script/package_app.sh
hdiutil verify build/OneBoard.dmg
```

最终安装包为 `build/OneBoard.dmg`。打包脚本选择可用开发证书并校验签名；日常安装测试应保持同一证书，临时 ad-hoc 签名不用于系统权限稳定性验收。开发时可用独立 Bundle ID：

```bash
ONEBOARD_BUNDLE_ID_SUFFIX=.dev2 bash script/build_app_bundle.sh
```

桌面、拖放和菜单栏集成测试需要可用的 macOS 图形会话。无显示器或无系统拖放服务的执行环境不能完成这些验收；逻辑测试通过也不等于真实鼠标交互已验收。

### 项目结构

```text
OneBoard/                 # SwiftPM 根目录
├── App_minimal/           # 极简可执行入口，创建并持有菜单栏项
├── App/                   # OneBoardKit 生命周期与设置窗口
├── Core/                  # 数据库、主题等基础设施
├── Modules/               # 截图、剪贴板、暂存、日历、状态、待办、网关与 AI
├── Shared/                # 菜单栏、权限、快捷键和公共服务
├── FinderSync/            # Finder Sync 扩展
├── Resources/             # 图标、Info.plist、entitlements
└── Tests/                 # XCTest
ProxySidecar/              # 内置 Rust 代理
script/                    # 构建、打包、卸载和集成验证脚本
```

可执行模块必须保持极简，业务逻辑位于 `OneBoardKit`。开发前阅读 [AGENTS.md](AGENTS.md)。

## 卸载

可以从 App 菜单选择「彻底卸载并清理残留…」，或在 DMG 中运行 `卸载残留.command`。源码目录也提供：

```bash
bash script/uninstall.sh
```
